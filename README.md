**SwiftStart** is a beginner-friendly Swift project that demonstrates the fundamental concepts of the Swift programming language through clean terminal output.

School Purpose Only.

## 🧭 Overview

SwiftStart runs a set of small demonstrations that introduce common Swift concepts. Each section prints formatted output so students can see how the concept works and how the code behaves when executed.

The repository name is `swiftstart`, while the application itself is called `SwiftStart`.

This project is designed for classroom practice, self-study, and beginners who want a simple reference for Swift basics.

## 🧰 Requirements

- Swift 5 or newer
- macOS, Linux, or another environment with Swift installed
- A terminal or command prompt

No external Swift packages are required.

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/LayerByte/swiftstart.git
cd swiftstart
```

Or download the project files and open a terminal inside the `swiftstart` folder.

## ▶️ Usage

Run the file directly with Swift:

```bash
swift main.swift
```

Or compile it first:

```bash
swiftc main.swift -o swiftstart
./swiftstart
```

On Windows, Swift support depends on your installed toolchain. Use a Swift-compatible terminal environment if needed.

## 🎯 Learning Objectives

After studying this project, students should understand how to:

- Declare constants and variables
- Work with strings, integers, doubles, and booleans
- Store values in arrays, sets, and dictionaries
- Use if statements and switch statements
- Repeat tasks with for loops and while loops
- Write and call functions
- Work safely with optionals
- Return multiple values with tuples
- Define enums, structs, and classes
- Use constructors through class initializers
- Apply closures to collections
- Handle simple errors with Swift error handling
